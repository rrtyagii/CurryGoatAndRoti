# Infomatic

Infomatic is an iOS app built with SwiftUI for browsing short topic cards and opening a detail view for each topic.

## Current App Flow

- Sign in with Google
- Browse learning cards in the main tab
- Open a card to read its topic details
- Navigate through the app using a tab bar

## Tech Stack

- Swift
- SwiftUI
- Google Sign-In
- Xcode / iOS Simulator

## Project Structure

- `Infomatic/` - app source code
- `Infomatic/Components/` - reusable SwiftUI views
- `Infomatic/Resources/` - bundled topic content and assets

## Running Locally

1. Open `Infomatic.xcodeproj` in Xcode.
2. Make sure your Google Sign-In configuration is set up in `Info.plist`.
3. Choose an iPhone simulator or device target.
4. Build and run the app.

## Status

This project is still under active development, so some tabs and features are placeholders or in progress.
